法悟空

把找律师，做成像「打车」一样简单

法悟空是一款法律服务平台 App：用户按案件类型快速匹配律师，明码标价在线咨询，从下单、沟通到评价全流程可追溯。本页包含 5 屏原型原稿、可点击的产品 Demo、完整 PRD 与核心流程。

01 / 项目背景

法律服务「贵、慢、不透明」，普通人不敢问

遇到租房押金、劳动工伤、婚姻财产、合同违约这类问题，用户的第一反应往往不是找律师，而是「先上网搜搜」「问问朋友」。不是没有需求，而是决策成本太高：不知道找谁、不知道多少钱、不知道过程靠不靠谱。

!三类核心痛点

01

信息不对称：不知道该找谁

律师数量多、专业方向差异大，普通用户无法判断「我的案子该找哪类律师」，只能依赖熟人推荐。

02

价格不透明：怕被「宰」

咨询费、代理费口径不一，缺少可比价的标准化服务包，用户在沟通前无法建立预算预期。

03

过程无留痕：服务不可追溯

以电话和线下沟通为主，服务进度、承诺事项缺少记录，出现纠纷时用户缺少维权依据。

◎机会判断

需求侧：租房、劳动、婚姻、合同类法律需求高频且标准化程度相对较高，适合用产品化方式承接。

供给侧：大量青年律师与中小律所缺少稳定获客渠道，愿意用「明码标价 + 平台派单」换取案源。

习惯侧：年轻用户已习惯在平台上比价、下单、评价，法律服务具备被「电商化」的条件。

结论：以「案件类型」为索引重构找律师路径，用透明定价降低决策成本，用订单与聊天留痕建立信任。
02 / 用户与场景

四类典型用户，一个共同诉求：快、准、不加价

把「法律需求」翻译成用户能理解的场景语言，而不是法条语言。四类人群的付费能力与决策动机差异明显，但都希望在小额、高频、低门槛的咨询里先获得确定性。

03 / 产品定位

一个「可按价筛选」的法律服务交易入口

不做法律百科，也不做律所官网；做的是把「找律师」这件非标服务，拆成可比较、可下单、可评价的标准商品。

让每一个普通人，
都能在 3 分钟内找到「对的律师」。
以案件类型为索引，以透明定价为前提，以过程留痕为信任基础。
明码标价 ¥39.9 起按案件类型匹配聊天与订单全留痕
NORTH STAR METRIC 周有效付费咨询订单数

只统计「完成支付且律师 48 小时内实际响应」的订单，避免用曝光或注册量虚增规模。

1差异化一：价格前置

列表页直接展示「¥xx/次起」，详情页给出图文 / 电话 / 面谈三档报价，用户在沟通前就能建立预算，减少询价流失。

2差异化二：案件类型索引

首页以婚姻家庭、租赁纠纷、劳动工伤、合同事务四大高频场景切入，而不是按律所或职级罗列，降低「我该找谁」的门槛。

3差异化三：过程可追溯

咨询在平台内完成，聊天记录、订单状态、服务承诺全部留痕，既保护用户，也作为平台处理纠纷的依据。

用户目标

3 分钟内完成「选类型 → 看律师 → 下单」；咨询前明确知道要花多少钱。

业务目标

把低频的「打官司」需求，转化为高频的「先问一句」小额咨询，形成复购。

平台目标

建立律师服务质量的可量化评价体系，用订单与好评率驱动供给端优胜劣汰。

07 / 核心流程

从「问一句」到「留一条评价」

流程设计的关键不是画得全，而是定义清楚每一步的异常分支：未支付怎么办、律师不响应怎么办、服务不满意怎么办。

流程一：用户咨询主流程

点击路径遵循「先分类、再比价、后沟通」三段式，保证用户在任何一步都能看到价格。

流程二：订单状态机

实线为主链路，虚线为异常分支。所有状态变更由服务端校验，客户端不可跳级。

流程三：律师入驻与质量考核

供给质量是平台的生命线：资质双校验 + 试运营 + 周期性考核，不合格直接下架接单权限。

09 / 版本规划与风险

先跑通一笔订单，再谈规模

V1.0 只做「能下单、能沟通、能评价」的最小闭环，把复杂的分账、会员、企业服务放到后面，避免第一版就做重。

V1.0 · 本期

最小可用闭环

  • 首页分类 + 律师列表 + 详情
  • 三档咨询报价与下单支付
  • 订单状态机（待付款 / 待评价 / 已完成）
  • 站内聊天 + 快捷提问
  • 个人中心与律师入驻入口
V1.1 · 增强

体验与供给治理

  • 评价晒单、标签化好评
  • 退款 / 售后工单
  • 律师工作台与接单提醒
  • 优惠券与首单立减
  • 举报与平台介入仲裁
V2.0 · 增长

效率与规模化

  • AI 法律问答预诊，降低无效咨询
  • 案件进度跟踪与材料清单
  • 企业版（合同审查包年）
  • 多城市供给分层运营
风险说明等级应对措施
律师资质合规虚假执业信息、跨属地执业P0执业证 + 身份证 + 律所三重校验，季度抽检，违规下架
资金与分账平台代收涉及支付合规P0与持牌支付机构合作，资金不过平台自有账户
服务纠纷律师未履约、用户不满意P0聊天与订单全留痕，48h 未响应自动可退

冷启动供给初期律师数量不足导致体验差P1先聚焦 2 城 3 品类，邀请制入驻，保底响应 SLA
