# 法悟空 · 法律服务 App（Fawukong）| 案件类型索引 · 明码标价咨询 · 全流程可追溯

把「找律师」做成像「打车」一样简单：按案件类型匹配律师、明码标价在线咨询，从下单、沟通到评价全流程可追溯。

本目录是一个**单文件网页项目**，用一份 `index.html` 同时承载三件事：

1. **可点击的产品 Demo**：按 Mockplus 原型 1:1 还原的 7 屏界面，可直接在手机壳里操作
2. **产品 PRD**：背景、用户、定位、信息架构、12 条核心需求、指标、版本规划与风险
3. **原型与流程**：5 屏原型原稿画廊（含原稿 PDF / 工程文件下载）、3 条核心业务流程图

同一套 PRD 另有一份可直接评审 / 归档的 Word 版本：`法悟空_法律服务App_PRD_v1.0.docx`（A4、31 页、含目录与页脚页码）。

## 在线打开

双击 `index.html` 即可浏览，无需安装任何依赖、无需构建。

如需在局域网给他人观看：

```powershell
cd fawukong_showcase
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## Demo 能点什么

| 界面 | 可交互内容 |
| --- | --- |
| 首页 | 四个案件分类入口、推荐律师卡片、顶部 Banner |
| 找律师 | 案件类型筛选、综合排序、价格升/降序 |
| 律师详情 | 图文 / 电话 / 面谈三档报价、选择下单、简介与评价 |
| 订单 | 全部 / 待付款 / 待评价 / 售后四个 Tab，支付、取消、评价、删除 |
| 消息 | 会话列表、未读红点、搜索框 |
| 聊天 | 快捷提问、发送消息、律师自动回复 |
| 我的 | 收藏 / 评价 / 浏览、成为专家（律师入驻）、设置、分享、关于 |
| 中间「+」 | 快捷发起咨询的弹层 |

**演示脚本（建议按顺序走一遍）**

1. 首页 → 点「婚姻家庭」：列表按类型过滤
2. 找律师 → 价格排序：¥39.9 ~ ¥288 可比价
3. 点任意律师 → 图文咨询：生成一笔待付款订单
4. 订单页 → 立即支付：状态流转为「待评价」
5. 消息 → 黄欣律师：发一句话，看自动回复
6. 我的 → 成为专家：律师入驻入口

> 演示数据全部在浏览器内本地模拟，刷新或点「重置演示数据」即可恢复初始 3 笔订单 / 3 条会话，不会产生任何真实交易。

## Word 版 PRD

`法悟空_法律服务App_PRD_v1.0.docx` 与网页版内容一致，面向评审、评审留档与研发交付：

| 项目 | 说明 |
| --- | --- |
| 版面 | A4、31 页，正文 10.5pt，标题 1~3 级自动编号样式 |
| 结构 | 封面 + 修订记录 + 自动目录 + 第 1~12 章 + 附录 A（演示数据）/ 附录 B（优先级定义） |
| 图表 | 33 张需求表 / 指标表（表头底色 + 边框），5 屏原型截图内嵌（3.17cm 宽） |
| 目录 | Word 目录域，右键「更新域」或按 F9 可刷新页码 |
| 页脚 | 「第 X 页 / 共 Y 页」域，随内容自动更新 |

打开后如提示更新域，选择「是」即可保证目录页码与最新内容一致。
